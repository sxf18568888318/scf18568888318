## 二、整装报价（参考「报价工坊」这类工具）

### 值得抄的 8 点

1. **企业工艺定额库**：把每个施工项目的人工单价、主材、辅材、工艺说明统一维护在后台，设计师只能选、不能随口填价 —— 这是解决"不同设计师报出来的项目和单价不一样"的根本办法
2. **选空间自动带项目**：选客厅/卧室/厨卫，系统自动带出该空间预设的施工项目和标准单价，再按实际情况增减
3. **多套报价模板**：刚需简装 / 轻奢整装 / 老房翻新 / 局部改造，新人设计师直接调用，减少漏项
4. **报价模板可设「必报项」**：防止少报项目导致后期自己贴钱或跟业主扯皮
5. **调价全程留痕**：单品调价、整单折扣、打包优惠都记录，管理者能复核
6. **报价审核机制**：大额报价、超折扣报价需主管审批后才能发给客户（对应你定的「低于 9 折需老板审批」）
7. **变更单联动**：施工中增项/减项走变更单，金额同步更新报价清单，应收自动跟着变 —— 这一条和我们定的「增项单独立项 + 书面确认」完全一致
8. **一键导出正式报价书 PDF**：项目、单位、数量、单价、总价列全，业主看得懂

### 还有一条特别契合我们

**进度节点绑收款计划**：报价确认签约后自动生成四笔应收（你已定 30/30/35/5），到节点自动提醒。行业里"工程管理绑收款计划、到点自动提醒"是标配，我们做进去成本很低。

## 三、全屋定制报价（参考第 1 个视频这类工具）

### 值得抄的 8 点

1. **按空间划分**：主卧 / 次卧 / 书房 / 餐厅 / 厨房各自独立管理，每空间单独出明细
2. **板材材质与厚度可选**：选材质即时显示单价和该空间总价；可做多方案对比表让客户挑
3. **五金按柜体自动测算**：按门板数、抽屉数自动算铰链/滑轨/拉手用量 —— 行业里五金漏报率能到 38%，是最常见亏钱点，这条优先级很高
4. **三种计价方式都要支持**：投影面积 / 展开面积 / 延米，且能按品类分别配置（衣柜投影、橱柜延米），跟你定的「投影和展开都要能选」一致
5. **改方案自动重算**：客户改尺寸或增减柜体，报价联动更新，不留旧版本发错单
6. **报价书内容完整**：空间分项明细 + 材质说明 + 五金清单 + 工期承诺 + 安装费明细，带品牌封面
7. **报价有效期 + 到期前提醒跟进**（对应你定的 30 天有效期）
8. **多门店价格体系**：总部统一基础价，门店按本地成本微调 —— 你有 2 家门店，这条用得上

### 建议先别做的

- **CAD 图纸自动拆板件 / 生成 BOM / 对接 CNC**：这是三维家、晨丰这类专业软件的核心，投入大、周期长，且我们现在连报价口径刚定。
- 先把「模板 + 空间带项目 + 自动算价 + 报价书」做扎实，等跑顺了再评估拆单。

## 四、我们系统现在已有什么（不重复造）

| 能力 | 现状 |
|---|---|
| 三级拆解（空间 × 工种 × 明细） | 报价工作台已按空间录入 |
| 建筑面积字段 | `quote-workshop.inc.js` 已有「建筑面积 ㎡」 |
| 水电按项 | 报价项目库里已有 `"unit":"项","mode":"按项"` 的水电条目 |
| 投影 / 展开 / 延米 / 按项 切换 | 整装与定制报价行都有下拉，可逐项切换 |
| 报价项目库 / 报价模板 | `reno_quote_item_library`、`custom-catalog-bom.inc.js`、板材与五金目录已有 |
| 业主报价书 | 已有简洁版 / 详细版预览与打印 |
| 收款分期 | 已有四阶段，比例 30/30/35/5 |
| 变更/增减项 | 报价工作台已有「增减项」页 |

### 真正的差距（要做的事，按优先级）

1. **统一工艺定额库**：把分散在各处的项目/单价收拢成一个可维护的库，设计师只能选
2. **多套报价模板 + 必报项**：按整装/定制各建 2～3 套，模板里标必报项
3. **五金自动测算**：按门板数、抽屉数、柜体类型算用量（先做规则估算，不做 CAD 拆单）
4. **调价留痕 + 折扣审批**：低于 9 折走老板审批，改动记录可查
5. **变更单联动应收**：增项确认后自动更新合同额与剩余应收
6. **报价书完善**：加上材质说明、五金清单、工期承诺、安装费、有效期、审批人
7. **有效期到期前提醒**

## 五、和已定口径的对齐检查

| 你的口径 | 参考做法是否冲突 |
|---|---|
| 面积按建筑面积 | ✅ 报价书首页写明即可 |
| 水电按项 | ✅ 但按项必须在备注写清包含的工作量/材料/工艺 |
| 柜体投影与展开都要能选 | ✅ 参考软件也是三种都支持，且可按品类分别配置 |
| 防水返高 1.8m、淋浴区到顶 | ✅ 写进工艺说明，不影响结构 |
| 增项单独立项、书面确认 | ✅ 参考做法的变更单正好对应 |
| 报价 30 天有效、9 折需审批 | ✅ 参考做法都有对应机制 |

**结论：你定的口径和行业通行做法不冲突，可以直接在上面加功能，不用改口径。**
