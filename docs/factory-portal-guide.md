# 工厂端操作与权限说明

## 角色

| 功能 | 老板 | 厂长 | 其他授权工位 |
|---|---|---|---|
| 查看订单档案、同订单资料、生产资料 | 是 | 是 | 按订单范围授权 |
| 上传订货单、板材单、五金清单、报价、特殊备注 | 是 | 是 | 否 |
| 查看/下载授权订单附件 | 是 | 是 | 按订单范围授权 |
| 登记板材、五金、外协等单户采购成本 | 是 | 是 | 否 |
| 查看单户采购成本金额 | 是 | 是 | 否 |
| 登记和查看工厂固定费用明细金额 | 是 | 是 | 否 |
| 查看人员工资明细、计薪标准及月度合计 | 是 | 否 | 否 |
| 查看工厂月/年利润及净利 | 是 | 否 | 否 |

厂长是工厂成本录入的主要操作人。工资明细、工资标准和月/年利润只对老板开放。前端隐藏只是界面控制，数据库 RPC、视图和存储策略也按角色限制。

## 订单资料

进入工厂生产 → 生产订单 → 订单档案 → 生产资料与版本。老板或厂长可以一次选择多个文件，包括图纸、订货单、板材单、五金清单、报价、合同、变更单、现场照片和特殊备注。Excel、CSV、PDF、Word 和常用图片可归档。新增资料写入共享 Supabase 订单档案，另一端刷新后同步可见。

附件存于私有 `factory-files` 存储桶。打开按钮会在当前点击事件中打开新标签，再获取短期签名链接，以兼容浏览器弹窗策略。无法预览的表格类文件会下载。文件最大 30 MB，访问需有对应订单读取权限。

## 单户采购成本

识别结果需要对照原单核对。可编辑每行数量、单价等字段；无法可靠识别时，勾选“无法核对明细，按实际付款总额登记”，输入付款核对总额并确认。系统将该单作为一条采购成本凭证保存，厂长和老板都能查看。

队列中的未入账采购单可以删除，已入账单据不会显示删除按钮。板材与五金采购记录都走相同队列逻辑。

## 固定费用

登记时选择“按月登记”“按年登记”或“其他 / 一次性”。按年金额自动均分到 12 个月，尾月吸收分币舍入差额；一次性费用只计入所选月份。老板和厂长可登记、查看工厂固定费用明细金额。

## 日常页面

- 生产订单按接单中、生产中、安装中和已完工分类；已完工单从进行中列表移出。
- 物资管理分五金和辅料；五金支持扫描采购单、匹配档案与相同物资去重后登记，辅料以手工登记为主。
- 考勤明细按日期折叠，并显示当天未登记员工。
- 工资汇总按月显示总额，仅老板可查看。
- 月 / 年净利中的固定人工显示月汇总；明细仍在人员与工资页，仅老板可查看。

## 收付款与凭证

老板或厂长可以在订单档案登记收款、付款，并为一笔记录附加最多 8 个 JPG、PNG、WEBP 或 PDF 文件，单个最大 20 MB。保存后凭证和现金流水关联存入私有云端。老板可在订单档案及月度现金流水打开凭证；厂长负责登记和上传，但看不到收款金额、工资和利润，设计师及工长无收付查看权限。供应商采购单登记的是订单成本；只有实际付款时再登记现金付款。

## 工资与利润

老板在“人员与工资”选择月份，查看月薪、日薪、计件合计；月薪结算后可为结算单登记正数或负数调整并写明原因。临时补贴等特殊人工单独登记，合并在该月工资合计与工厂固定人工中。净利润页只显示按月汇总的固定人工，不重复展示员工逐条明细。

## 扫描与入库

扫描采购单后先核对原件，低置信度或识别不到的内容手工补录。板材与五金订单成本按单独立入账，不自动生成实际付款。五金库存扫描会匹配已有物资并合并同项数量；无法匹配的名称保留为可编辑行，可先创建物资档案，返回后继续补全原表和入库。点击一次“手动添加一行”只应增加一行；若遇到重复，可刷新页面后重试并核对数量。

## 本次界面调整

采购单保存后回到当前客户订单档案，保留原来查看的页面位置。档案内的设计图、订货资料、五金清单、报价、合同与备注可在私有附件区查看或下载。设置和账号管理入口在侧栏底部纵向排列；手机窄屏收为图标入口，减少挤压主菜单。

## 备份与恢复

代码备份至少包含 `app/`、`share-preview-site/dist/`、`supabase/migrations/`、`netlify.toml`、`.env.example` 和本说明。排除 `.env`、`node_modules`、`document-deps`、`__pycache__`、临时文件和真实业务导出。部署前保存一份带日期的 ZIP；数据库按 Supabase 项目备份能力另行保留，不能用代码 ZIP 替代。
# 登录账号与密码设置

- 登录支持原邮箱账号；老板完成账号映射后，也可使用 `yj18568888318-01` 这类登录名。
- 所有已登录用户可在左下角“设置”验证当前密码并修改自己的密码。
- 老板可通过左下角“管理账号”查看真实账号名单，核对姓名后手工填写连续登录编号；只映射现有账号，不为凑编号新增账号。
- 老板可新增账号、调整系统已有角色，或单个/批量重置密码。角色权限仍由服务端执行；账号目录不显示邮箱和密码。
- 若要统一初始密码，老板在批量重置时自行输入，并先核对选中的账号名单。
