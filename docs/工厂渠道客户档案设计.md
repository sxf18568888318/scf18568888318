# 工厂端 · 渠道客户档案设计

2026-11-12 · 按老板口述需求整理，待确认后进入开发

---

## 一、要解决什么

工厂不只接自家门店的单，还对接**装修公司这类渠道客户**（例如「卓越装饰」）。一个渠道客户会连续下好几个单，现在这些订单散在订单列表里，看不出「这个渠道一共给了我们多少活、哪些还没结、有什么特殊要求」。

要做的就是一个**按渠道客户归拢的档案**：

> 点开「卓越装饰」→ 看到这家公司的基本信息、所有历史订单（5～6 单）、每单的金额和进度、累计数据，还能随时加备注。

---

## 二、和门店「业主客户」不是一回事

| | 门店业主客户 | 工厂渠道客户 |
|---|---|---|
| 是谁 | 装修业主（张先生、李女士） | 装修公司 / 设计师 / 分销渠道 |
| 一个档案对应 | 一户人家、一个项目 | 一家合作单位、多个订单 |
| 关心什么 | 报价、跟进、签约、工地进度 | 渠道分类、渠道价、账期、累计订单与结算 |
| 归属板块 | 门店端（整装 / 全屋定制） | **工厂端** |
| 权限 | 销售 / 设计师 | 老板 + 厂长（渠道价与毛利按现有角色规则） |

> 两者不合并。渠道档案挂在工厂模块下，订单仍用统一项目编号 `AJ-2026-0118`。

---

## 三、档案字段

### 基本信息

| 字段 | 说明 |
|---|---|
| 渠道名称 | 如「卓越装饰」，必填、唯一 |
| 渠道分类 | 可自定义分类（见第四节） |
| 联系人 / 电话 | 可多个联系人 |
| 合作状态 | 合作中 / 暂停 / 已终止 |
| 结算方式 | 现结 / 月结 / 按单结；账期天数 |
| 报价体系 | 渠道价 / 零售价 / 一户一议（关联到渠道专属价格表） |
| 开票信息 | 按需 |
| 建档日期 / 负责人 | 自动 + 手填 |

### 备注时间线（你特别提的）

- 每条备注：**内容 + 记录人 + 时间**，可追加、不可覆盖
- 支持标记类型：常规沟通 / 价格约定 / 质量要求 / 投诉 / 结算提醒
- 典型用途：「这家用 E0 级板，封边必须 PUR」「每月 25 号对账」「上次五金升级免费，下次起收费」

---

## 四、分类体系

分类要能自己加，不写死。建议初始给这几类：

```
装饰公司 / 整装公司 / 独立设计师 / 分销商 / 散单渠道 / 其他
```

- 列表页支持按分类筛选、按名称搜索
- 分类可改名、可停用；停用后已有档案仍保留原分类
- 分类维度后续可直接用于经营看板「各渠道贡献订单数 / 金额 / 毛利」

## 五、页面结构

### 1. 渠道客户列表（工厂端新增二级页）

```
[分类筛选] [搜索框]                        [＋ 新建渠道客户]

渠道名称     分类      合作中订单   累计订单   累计金额    未结金额    最近下单
卓越装饰    装饰公司      2          6      ¥186,400    ¥12,000   11-08
××整装      整装公司      1          3       ¥92,800    ¥0       10-29
李设计工作室 独立设计师    0          1       ¥18,600    ¥0       09-14
```

### 2. 渠道客户详情（点开「卓越装饰」）

**顶部卡片**：渠道名称、分类、联系人、合作状态、累计订单数、累计金额、未结金额、累计毛利

**Tab 1 · 订单列表**（核心）

| 订单号 | 业主 / 小区 | 金额 | 状态 | 下单日 | 交期 | 已收 | 操作 |
|---|---|---|---|---|---|---|---|
| AJ-2026-0118 | 华强城 3 号楼 | ¥38,600 | 生产中 | 11-08 | 11-28 | ¥20,000 | 查看 |
| AJ-2026-0102 | 建业桂园 2 单元 | ¥42,800 | 已交付 | 10-21 | 11-05 | ¥42,800 | 查看 |
| … | | | | | | | |

- 支持按状态、时间筛选
- **「＋ 新建订单」直接挂到当前渠道**，不用再选一次渠道
- 点订单跳到该订单档案（复用现有订单详情页）

**Tab 2 · 备注时间线**：按时间倒序，随时添加

**Tab 3 · 对账 / 结算**：按账期列出应收、已收、未结，可导出

**Tab 4 · 基础资料**：编辑基本信息、分类、报价体系

## 六、数据怎么落

现有数据库里已有 `factory_orders` / `work_orders` 等订单表。建议：

- 新增 `channel_customers`（渠道档案主表）：id、名称、分类、联系人、结算方式、状态、报价体系、创建时间
- 新增 `channel_notes`（备注时间线）：渠道 id、内容、类型、记录人、时间
- 订单表加 `channel_id` 外键（可为空，空 = 门店自营单）
- 汇总数据用视图或 RPC 算，不手工维护，避免和订单对不上

> 这一步要动数据库结构，所以**单独作为一期做**，做完先在你本地/验收版点一遍再合并。

## 七、权限

| 功能 | 老板 | 厂长 | 设计师 / 工长 |
|---|:---:|:---:|:---:|
| 查看渠道列表与档案 | ✅ | ✅ | ❌ |
| 新建 / 编辑渠道、加备注 | ✅ | ✅ | ❌ |
| 看渠道累计金额 / 毛利 | ✅ | 按现有规则（毛利可能仅老板） | ❌ |
| 新建挂渠道订单 | ✅ | ✅ | ❌ |

沿用你定的原则：**工资明细与工厂净利只对老板开放，厂长不开放**。渠道毛利是否也给厂长看，参考现有工厂毛利权限，先保持一致。

## 八、验收场景（做完照这个点一遍）

1. 新建渠道客户「卓越装饰」，分类选「装饰公司」，加一条备注「每月 25 号对账」
2. 在该渠道下连续建 3 个订单，分别给不同状态
3. 回到列表，确认「累计订单 3、累计金额、未结金额」自动算对
4. 点开详情 → 订单列表能看到 3 单，点任一单能跳到订单档案
5. 换分类筛选、搜名称，能筛出来
6. 用厂长账号登录，确认看不到的字段确实看不到

## 九、还要你定三件小事

1. **分类**就按上面 6 类，还是你有自己的叫法？
2. **渠道价**要不要单独一套价格表（和门店零售价分开），还是每单在订单里填？
3. **渠道毛利**厂长能不能看？（我倾向：跟现有工厂毛利权限保持一致，先不额外放开）
