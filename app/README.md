# 整装与全屋定制经营台（单机试用版）

## 2026-10-06 本机改善版

当前可修改框架请使用项目根目录的“打开安居本机预览.cmd”，并阅读“本机改善版说明.md”。新工厂四模块、订单成本 / 库存 / 考勤 / 收支，以及定制报价工作台使用 `framework-preview.js`。修改 include 源码后运行 `sync-quote-preview.ps1`，刷新本机页即可。以下原单机应用说明属于 `index.html` 的旧试用流程，不代表新框架原型的功能边界。

## 总体框架交互演示

打开 `framework-preview.html` 可查看“整装、全屋定制、工厂生产 + 员工端/管理端”的模块框架演示。可在右上角切换演示身份，点击左侧模块和页面查看流程。页面中的客户、订单、数量和价格均为虚构示例；表单操作只用于演示，不会保存到正式业务数据。

框架文档：`../docs/superpowers/specs/2026-10-03-anyang-business-suite-framework-v0.1.md`。

## 打开方式

在 Windows 上用 Edge 打开本目录中的 `index.html`。本试用版不需要安装或联网，客户、报价、跟进和成本记录保存在当前浏览器的本地存储中。

## 试用步骤

1. 默认进入设计师端，选择“设计师A/B/C”体验自己的客户、跟进和报价。
2. 第一次点击“老板入口”时设置本地试用密码，进入老板工作概览、团队进度和成本台账。
3. 老板端可在“设置与备份”维护设计师名称，并导出/恢复 JSON 备份。
4. 首次打开带有虚构演示客户和报价；点击横幅右侧“清除演示样例”可清理这些样例。

## 试用边界

这是单机试用版。老板密码用于减少误入，不等同于正式账号权限；成本数据保存在当前浏览器中，不要把本机版作为多人共享或工资保密系统。设计师界面不显示成本、工资和利润；正式部署前需将账号验证和数据权限移到服务端。当前成本模块是手工费用台账，不自动计算毛利、净利或提成。
